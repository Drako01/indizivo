# INDIZIVO — Identity v0.1
**Status: design direction approved; trademark unverified.**

Indizivo is a coined name inspired by Italian indizio (clue). It suggests investigating symptoms through evidence.

**Tagline:** Find the cause. Fix with confidence.
**Secondary:** From symptoms to evidence.
**Spanish:** Encontrá la causa. Resolvé con confianza.

**Symbol:** strong I, three diagnostic signal arcs, amber evidence dot. Activity Bar uses monochrome currentColor.

**Palette:** Graphite #18232F; Graphite Deep #101922; Diagnostic Teal #35C2B1; Teal Dark #087B70; Signal Amber #F6BA65; Off White #F4F7F8; Slate #637382. Inside VS Code, native theme tokens take precedence. Colors never carry status alone.

**Typography:** Inter/Manrope preferred for marketing, system UI fonts in VS Code. No unlicensed font bundles.

**Personality:** measured, precise, practical, reassuring without overclaiming.

**Logo:** media/indizivo-icon.svg; media/indizivo-activity-bar.svg. Marketplace PNG 128 and other export variants to be verified before publishing.
