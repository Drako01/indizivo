# Third-party notices

The Indizivo runtime currently uses Node.js built-in modules and the VS Code Extension API. The repository declares @vscode/vsce as a development-time packaging tool; it must not be bundled as a runtime dependency.

Before every public release, inspect the final VSIX and all transitive/bundled packages to generate exact third-party notices and verify license compliance. Do not treat this placeholder as an audited SBOM.
